# PRO Китай — лендинг индивидуальных туров

[Смотреть макет в Figma](https://www.figma.com/design/ExhjfrVFhaRJuqIv0c5Byq/PRO-%D0%9A%D0%B8%D1%82%D0%B0%D0%B9?node-id=0-1&t=RjxBCKPK2wHOKmxn-1)

Данный лендинг разработан в рамках дисциплины **«Вёрстка»** и представляет собой адаптивную страницу, посвящённую организации индивидуальных туров в Китай. Применена методология **Mobile First** с тремя ключевыми брейкпоинтами: 375px, 768px, 1024px.
